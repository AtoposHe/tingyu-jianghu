# 听雨江湖 · 国风 Q 版原型

当前包括村庄探索、老村长分支对话、武师武青山与回合制切磋。主角和武师只使用国风 Q 版透明 PNG。游戏已移除其他人物样式与换装试作入口。

游戏开场为“第一回：一封旧信，半枚镖牌”，交代景和七年暮春、江南青州听雨村，以及十八岁的主角追寻失踪师父的来由。江湖手记引导问镖牌线索、完成武馆切磋与支线拾芳，并保存完成标记。完整故事与后续规划见 docs/story-and-opening.md。

与武青山的切磋现使用手绘“听雨武馆 · 演武院”背景，技能观赏页同步更新。背景按对手 ID 配置，后续人物可指定不同场景；说明见 docs/battle-scenes.md。

新增听雨武馆、溪南铁铺、杏花酒肆与村长家，并布置十二处可收集花卉。点击花草只会走近，**按 F 确认后才收集**；B 打开行囊，B / Esc 关闭。收藏数量与 60 秒再生时间自动保存在当前浏览器。说明见 docs/town-life.md。

听雨村现为 1600 × 1000 的分层图片场景：地形、客舍、武馆、村居、村长家、酒肆、左向铁铺、花草与前景老树分别叠加。石阶和西巷缓坡可实际通行，河流、台地石壁及建筑会阻挡移动。详细布局与素材记录见 docs/village-map.md。

## 启动

GitHub Pages 自动发布配置已准备，操作说明见 [docs/github-pages.md](docs/github-pages.md)。本地生成发布包使用 `python3 tools/build_site.py`，输出 `_site/`。

浏览器直接打开 index.html 即可。macOS 也可双击 start.command，或运行：

```sh
python3 serve.py
```

默认地址 http://127.0.0.1:8765 ，端口占用时自动选择空闲端口。Ctrl+C 停止服务。

本地服务对页面和素材禁用缓存。修改脚本或样式后可运行 `node tools/version-pages.cjs` 更新页面内的资源版本地址；这也能让此前已缓存旧资源的浏览器获取新文件。新版武馆入口：http://127.0.0.1:8765/?v=dojo-painted-2 。

## 玩法

- WASD／方向键移动，或点击地面寻路。点击人物自动走近交谈，靠近后也可按 E。
- 开场点击“踏入听雨村”开始；页头“江湖手记”可回顾背景与前期目标。
- 背包右键选中物品后按 F 丢弃 1 件，Esc 取消确认。没有右键确认目标时，F 不会丢弃物品。
- 主角移动时播放八帧 Q 版跑步循环，双腿交替迈步、摆臂与衣摆飘动；向左时镜像转身，停下或遇障碍后回到待机。
- 点击“寻访武师”，与武青山选择“开始切磋”进入演武场。
- 左上单行目标会依次引导拜访村长、初战学艺、打坐、复战与支线拾芳；村长对话中可询问旧镖牌，武师位于东岸石阶上方。
- 点击普通攻击或按数字 1 出拳，随后 NPC 自动回击，动画期间锁定行动。
- 主角初始气血 100、灵力 20，尚未习得技能。初战落败后向武青山学习推山掌与吐纳法。
- 双方整回合结束分别回灵：新手 2、武师 3。推山掌消耗 8 灵力并护势减伤一次；主角学会后按 2 释放。地图按 R 打坐，每两分钟灵力上限 +1、气血上限 +2。
- 一方气血归零后结算，可再战或回村庄。己方回合可认输，每次切磋重新初始化。
- 游戏只保留国风 Q 版。战斗页“招式观赏”可单独播放或定格查看推山掌特效。
- characters.html 展示完整 Q 版角色、八张战斗动作原图和八帧跑步图集。
- 原型不含后端和账号。花卉背包、采集再生时间、修为、已学武学和开场目标标记保存于当前浏览器；地图位置、当前对话和切磋状态刷新后重置。

## 素材与动画

assets/q/ 内有八张战斗姿态 PNG，以及 hero-run-sheet.png 八帧透明跑步图集。使用内置 image_gen 生成，最终采用素材全部复制进项目。跑步图集为 1774 × 887，采用四列两行。

当前通过关键姿态切换，配合前冲、后退、受击晃动、拳风、掌风和飘字表现攻防。这是关键姿态动画，尚不是连续逐帧或可拆分换装的骨骼动画，姿态间仍有少量衣纹和头发差异。

地图跑步按实际位移推进循环，每 104 个地图单位跑完一轮；同一图集只加载一次，各帧使用固定缩放和地面锚点，保留腾空动作。起停约 0.1 秒过渡，并在落脚时显示轻微尘环。停止、对话、切磋和回到村口会停止跑步；碰撞时不会原地跑。说明与完整提示词见 docs/run-animation.md 和 assets/q/run-provenance.json。

生成提示词与素材说明见 docs/q-sprite-prompts.md；技能特效说明见 docs/fx-notes.md。地图已换成分层 PNG，老村长使用新绘制的 Q 版 PNG。

| 文件 | 用途 |
| --- | --- |
| game.js | 地图、碰撞、寻路与对话 |

| battle.js、battle.css | 战斗分区、动作调度与特效 |
| battle-scenes.js | 按对手身份选择背景、图片加载与等比例裁切 |
| sprites.js | PNG 加载与关键姿态选择 |
| hero-run.js | 按实际位移推进地图跑步循环与起停过渡 |
| sprite-data.js | 素材边界与脚底锚点 |
| battle-fx.js | 新绘制的掌风、碎光、聚气和命中反馈 |

| characters.html | Q 版人物与动作图查看页 |
| assets/q/ | 最终 PNG 与来源记录 |
| tools/inspect-sprites.cjs | 读取透明度、边界和锚点，不修改图片像素 |

更新角色素材后，调整 assets/q/provenance.json 并运行 node tools/inspect-sprites.cjs。

交互更新：采集和交谈共用同样大小、位置的提示且互斥显示；按 F 即时收集，不再等待或显示进度条。左上建筑现名“枕间客舍”，原“枕河客舍”更名为“村长家”，老村长在门前；铁匠铺移至东侧，入口朝左，其余建筑位置保持不变。

修炼篇：境界、统一人物属性与武青山授艺流程见 [修炼与武力系统](docs/martial-system.md)。地图按 R 查看修为，习得吐纳法后可主动打坐；战斗按 2 使用推山掌。

境界已改为六境各十段，以灵力上限直接划分；境界上限会暂停修炼，等待后续突破任务。R 页面可选择已学内功并观看盘腿修炼动画；B → 功法典籍可阅读全部已学内功与招式原文。

初剑篇：复战后向武青山领取赠剑凭条，前往村东溪南铁铺免费领青锋剑。行囊顶部显示金币，物品页可切换武器。村外石坡按 F 采矿，铁铺可用金币买剑、交矿锻剑或出售余矿。装备剑后地图显示持剑，战斗普通攻击变为基础劈砍。详见 [初剑篇说明](docs/forge-and-first-sword.md)。

听雨林篇：从听雨村南口沿路进入第二张可行走地图，矿脉与随机药草可按 F 采集；西北竹林有杏竹医馆，可治疗、购药和卖草。地图按 C 查看身体与修改名字；伤势跨地图和切磋保留。基础劈砍缩短为 0.68 秒并平滑过渡。详见 [听雨林与医馆](docs/forest-and-care.md)。

听雨林已按听雨村画风重绘为铺石林径与自然溪流；东西道路通到地图边界并预留后续地图接点。气血每次战后回满，持续伤病按身体部位保存，按 C 查看。详见 [听雨林与身体状况](docs/forest-and-care.md)。
