# 第一回：一封旧信，半枚镖牌

## 世界与人物

这是架空武侠世界。故事发生在景和七年暮春，江南青州的听雨村。十年前的夜渡镖案早已沉寂，近来重开的商道却又出现旧镖号。

主角十八岁，自幼由清河镖局收养，做过杂役、认得商路，但仅会粗浅拳脚。师父三个月前随押镖队失踪。主角找到一封写给“听雨村长”的旧信和半枚水纹镖牌，来到听雨村寻找师父，也寻找自己的来处。

整体方向是“小镇立足 → 商道寻踪 → 夜渡旧案 → 身世与江湖选择”。战斗是追查途中自保和磨炼的手段；人物关系、承诺与线索串起成长动机。

## 已实现的开场与前期流程

每次载入游戏先展示开场，包含时间、地点、身世和三项引导。阅读后点击“踏入听雨村”；已读过则显示“继续前路”。页头“江湖手记”可随时回顾（交谈、战斗或背包中需先退出当前界面）。

1. **拜访村长，询问旧镖牌。** 点击左上引导自动走到村长家，在对话中选择“请您看看这枚旧镖牌”，读完并继续后记为完成。村长透露师父曾追查夜渡案，建议主角先找陆青山。
2. **武馆试拳，学会进退。** 与陆青山完成一次切磋后返回地图，胜负均算完成；主动认输不算。这是修炼的起点，不强迫新手赢下第一次战斗。
3. **支线拾芳，熟悉村路和行囊。** 按 F 瞬时收集任意一份花材，按 B 可查看行囊。这是可提前完成的生活引导，不阻塞剧情询问和战斗。

三个标记保存于当前浏览器 `tingyu-story-v1`，与背包存档独立。左上保持单行目标，完成后切换至下一项目标，全部完成则打开江湖手记。故事页不会清空已有花卉收藏。

## 后续剧情规划（尚未开放）

- **杏花酒肆：** 与掌柜、船夫核对师父最后出现的时间；对同一件事听到不同说法，形成第一组可比较的线索。
- **溪南铁铺：** 辨认镖牌水纹，发现镖局旧印曾被重铸；通过委托接触打造与修理，而非单纯购买属性。
- **夜渡河埠：** 顺商道寻镖队，安排护送、调查和一次可避开的冲突，让克制与出手都产生后续回应。
- **长期成长：** 武学师承、同伴信任、欠下的人情及对旧案的选择，与战斗养成共同推进主角的身世线。

以上目前只在手记中展示规划，没有虚构可进入的商店或后续任务。

## 背包丢弃

右键一个已有物品 → 显示“丢弃物品名 ×1？” → 按 F 确认。也可点击确认按钮。没有右键选定待丢弃物品时，背包中的 F 不执行操作。每次只丢 1 件，最后一件被丢弃时移除该堆叠。Esc 先取消确认，再按一次关闭背包；B 直接关闭并取消待确认操作。数量立即持久保存，丢弃不会刷新地图花材再生时间，不能撤回。
