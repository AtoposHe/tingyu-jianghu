# 修炼与武力系统

本次只开放基础吐纳、推山掌和武青山的授艺流程。地图、采集和行囊玩法沿用现有内容。

## 全世界共用的尺度

境界依次为 **淬体 → 通脉 → 凝气 → 归元 → 化境 → 宗师**，每境分一、二、三重，共 18 层。以层级 L = 0…17 表示。普通村民也有同样的基础属性；境界名称不代表人人好斗。

修为 C 是累计主动静修的秒数（剧情中称“息”）。第 L 层的累计门槛为 `300 × L × (L + 1)`。当前层升下一层需要 `600 × (L + 1)` 息：首层 10 分钟、下一层 20 分钟，再下一层 30 分钟。宗师三重为当前上限。功力不会在突破时倒退。

每积累 120 息获得一份根基，令 R = floor(C / 120)。所有角色使用以下属性公式，没有给 NPC 额外乘区：

| 属性 | 共用公式 |
| --- | --- |
| 气血上限 | 100 + 12L + 2R |
| 灵力上限 | 20 + 3L + R |
| 武力 | 18 + 4L |
| 防御 | 4 + 2L |
| 每整回合恢复灵力 | 2 + floor(L / 3) |

主角开始为淬体一重：气血 100、灵力 20、武力 18、防御 4、回灵 2。静修两分钟后为 102 气血、21 灵力；十分钟突破到淬体二重后为 122 气血、28 灵力、武力 22、防御 6。

武青山为通脉二重（L=4，C=6000）：气血 248、灵力 82、武力 34、防御 12、回灵 3。老村长未习战技，沿用淬体一重的凡人根基。`Martial.people` 统一定义所有已出场人物；添加新 NPC 时应使用 `Martial.person`，不得在战斗代码里另写一套数值。

## 回合、消耗与伤害

- 一整回合为少侠一次行动、对手一次行动。双方都存活时，整回合结束各回一次灵力，上限封顶；普通攻击自身不回灵。
- 普攻不耗灵力：伤害 = round(max(1, 自身武力 − 对方防御))。
- 推山掌双方都消耗 **8 灵力**，伤害 = round(max(1, 武力 × 1.4 − 对方防御 × 0.7 + 4))。
- 推山掌先沉肩护住中门再吐劲出掌，因此同时获得一次 **60% 减伤的护势**。护势只抵挡下一次攻击，不叠加，被命中后消失。目标有护势时，上述原始伤害再乘 0.4 后取整，最低 1 点。
- 没学会技能或灵力不足时，不能施掌、不能扣费或跳过回合；武青山在偶数回合、有足够灵力时施掌，否则普攻。双方完全共用技能规则。
- 切磋前气血、灵力回满，切磋后消除伤势。切磋不额外奖励修为，不会靠反复开战刷修炼进度。境界成长来自日常打坐。

未经修炼的主角连续普攻会在第 3 回合落败；学掌后尽量使用推山掌，可撑到第 5 回合，仍无法打败武青山。这来自正常伤害、护势和回灵计算，没有剧情强制扣血。之后修炼充分可以按同一公式自然获胜。只使用普通攻击不会凭空增加存活回合。

## 授艺与修炼操作

1. 到武馆与武青山切磋。主动认输不触发授艺。
2. 正常落败后点“向武师请教”，回到地图自动接续传掌、讲吐纳的对话。
3. 读完后选择“学习推山掌与吐纳法”，技能和修炼同时解锁。中途离开或刷新，下次交谈仍可继续学习，不会卡住。
4. 战斗按 1 出拳、按 2 施掌；技能按钮展示花费、护势与不足灵力状态。战斗中不能打坐。
5. 地图按 R 或点“打坐修炼”，再点“开始打坐”。呼吸光圈表示修炼进行中，每秒一息、每两分钟才增加一点灵力上限。可立即再切磋体验掌法，不要求等待突破。
6. 收功、关闭修炼界面、切到后台或离开页面都暂停；不发放离线收益，长时间挂起的一帧也不补发修为。每五息自动存档，暂停和关闭时立即保存已完成的息数。

修为、授艺状态和复战记录保存于当前浏览器 `tingyu-martial-v1`，不清除既有剧情线索、花材和行囊。更新前曾完成的旧切磋不能直接解锁新武学，需要重新体验本次授艺。

## 实现与检查

`martial.js` 是世界境界、人物属性、技能数据和修炼存档的唯一来源；`combat-rules.js` 只结算行动与回灵；`cultivation.js`/`.css` 提供打坐界面与主动计时；`game.js` 接入授艺对话；`story.js`/`story-view.js` 更新手记引导。

新增检查覆盖属性在每一息、每次突破时单调增长，所有人物共用公式，学艺门槛、存档恢复、2 分钟与 10 分钟边界、后台和关闭暂停、长帧保护、3/5 回合平衡以及后期自然获胜。真实地图输入检查覆盖落败后对话衔接、显式学习、R 界面和复战目标。
