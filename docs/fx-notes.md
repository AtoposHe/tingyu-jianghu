# Q 版专用战斗与推山掌特效

游戏与人物页现在只显示国风 Q 版；原画、分层试作和服装切换入口已移除，运行页面不再加载旧角色绘制器。

## 新绘制的素材

本轮使用内置 image_gen 绘图工具，生成并保存两张透明 PNG：

- `assets/fx/palm-wave.png`：青玉色光掌、鎏金云纹、向后的气流尾迹，默认向右。
- `assets/fx/palm-impact.png`：白金色核心、青玉碎光、断裂金环与云纹爆发。

完整生成提示词及原始输出路径记录在 `assets/fx/provenance.json`。采用素材均完整复制到项目，透明通道保留。

## 动画顺序

1. **蓄力**：场景轻微压暗，武师脚下出现金色阵环，青金光点向身体聚拢。
2. **释放**：武师张掌，绘制的大型光掌从手部推进，后方有弧形气流。
3. **命中**：光掌到达少侠时结算气血与灵力，叠加绘制的碎光爆发、双层震波和粒子。
4. **受击**：显示 Q 版受击姿态、击退与大号伤害数字，加入短暂顿帧和小幅镜头震动。
5. **收势**：碎光、光环与粒子淡出，再解锁下一回合。

推山掌的演出时长为 2.8 秒，命中时刻为 64%。数值规则保持原有设定，主角仍未习得技能。

## 观赏与实现

`effects.html` 提供独立观赏页，可以播放、暂停，点击阶段按钮定格，或拖动进度条。观赏页不改变游戏数据，与战斗复用 `battle-fx.js`。

- `battle-fx.js`：阶段计算、绘制素材、气流、聚气与扩散粒子、镜头反馈。
- `battle.js`：Q 版角色、回合控制、命中停顿、实际资源结算。
- `battle-moves.js`：招式时长和命中点。
- `effects-preview.js`：独立观赏页控制。

特效仍限制在人物舞台内，不会覆盖上方的气血／灵力卡片。开启系统“减少动态效果”时会停用镜头震动与命中闪白。

检查命令：`node tests/battle-fx.test.cjs`，其余规则检查见 README。
