# 听雨村 · 分层图片地图

地图使用 1600 × 1000 的逻辑坐标。assets/maps/ 与 assets/town/ 保存当前采用的地形、建筑和花草 PNG，运行时真实叠加，未将场景预合成成一张静态截图。

## 地图结构

| 区域 | 布置与通路 |
| --- | --- |
| 南埠村口 | 主角出生于南侧石板路，沿路向北进入村中 |
| 西侧村居 | 双户民居、晾晒、柴堆、菜圃与前景老树 |

## 图片与绘制顺序

1. terrain.png：山景、竹林、地面、台地、石壁、石阶、缓坡、溪流、拱桥、菜畦与溪埠。
2. assets/maps/ 下的 inn.png、homes.png 与 assets/town/ 下的 dojo.png、winehouse.png、guesthouse.png、smithy-left.png：透明建筑图片，分别独立定位。
3. 人物与建筑、tree.png 依脚底／建筑基座的深度排序。老树图片重复用于四个前景位置；角色走到树冠或屋檐后方时，该遮挡物渐隐到 42%，便于辨认。
4. 路径、落脚尘环与少量飘叶仍由 Canvas 绘制。

素材采用内置 image_gen 绘制。完整提示词、最终来源与客栈透明抠图的补充指令记录在 assets/maps/provenance.json，当前使用的 PNG 均保存在项目中，已清理退出运行的旧素材。

## 高差、碰撞与寻路

village-map.js 是所有布局、人物位置和导航的共同配置。台地逻辑高度分别为 72 和 88；台阶与缓坡连续插值高度，角色在这些路段适度减速。地图本身已经绘出高低投影，不再额外偏移角色的屏幕 Y 坐标。

建筑基座、河面、石壁和树干限制脚底通行。角色必须走石阶、缓坡或石桥，不能横穿石壁；交谈也要求站在同一高度附近，避免隔着台地对话。寻路采用 16 单位网格 A*，每段移动同时检查中间点与高度变化，并精确抵达路径节点，防止在窄桥转角卡住。

调整建筑时，需一起修改 box（图片位置）、depth（前后遮挡基线）、solid／trunk（脚底碰撞），不要仅移动美术图片。
