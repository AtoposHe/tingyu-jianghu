# 按对手选择战斗场景

与武师武青山切磋时使用“听雨武馆 · 演武院”，背景为新绘制的全景 PNG。技能观赏页也使用这一武馆背景。

- assets/battles/dojo-courtyard.png：2172 × 724，武馆主殿、石阶、兵器架、木桩、鼓与开阔石坪。内置 image_gen 绘制，完整提示词和来源见同目录 provenance.json。
- battle-scenes.js：独立场景配置、对手映射、图片缓存与等比例裁切。trainer 对应 dojo；elder 与未配置身份对应 village（原村中空地）。这只配置背景，不会给村长新增切磋入口。
- game.js 显式传入 activeNpc.id；battle.js.start(opponentId) 根据身份选择场景。再次切磋保留此前的对手和场景，不会重置为默认背景。
- 场景就绪前暂时禁用出招；加载失败时尝试村中备用背景。异步加载带版本检查，先前场景的迟到结果不会覆盖当前场景。
- 背景使用 cover 裁切保留建筑比例；人物、血量与灵力布局、攻击特效和伤害规则保持原逻辑。

新增对手场景时，在 scenes 增加图片和地点说明，再在 opponents 将人物 ID 映射到对应场景即可。

tests/battle-scenes.test.cjs 验证场景映射、宽窄画幅裁切、异步切换、再次切磋和出招入口。其他战斗规则与地图交互检查同时通过。本轮浏览器自动化仍然连接超时，未完成浏览器中的画面核对。
