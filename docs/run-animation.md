# 主角地图跑步动画

## 绘制素材

- 工具：内置 image_gen，transparent_background=true。
- 参考：assets/q/hero-idle.png，保留青白衣衫、金玉冠、腰饰、长发与 Q 版比例。
- 新图：assets/q/hero-run-sheet.png，1774 × 887，真实透明 PNG；四列两行，逐行从左到右读取八帧。
- 完整提示词、参考与原始生成路径：assets/q/run-provenance.json。
- 原始 PNG 完整保留；工具仅读取透明区域，运行时按 source rectangle 取帧。

跑步姿态包括伸腿、承重、蹬地、腾空和另一侧交替迈步。左右方向共用图集，向左时镜像；上下移动延续最近的水平朝向，使用相同的三分之四视角跑步动作。

## 播放与接入

- hero-run.js 根据**实际移动距离**推进八帧循环，104 个地图单位为一轮，在目前 172 单位/秒的移动速度下约 13 帧/秒。
- game.js 在键盘移动、点击地面寻路和自动走近 NPC 时计算实际位移；到达目标、受阻或松键后约 0.1 秒回到待机。
- 对话、切磋、回到村口立即停止跑步。路径跨越已抵达网格点时不额外插入停顿帧。
- 全部跑步帧共用固定尺寸和地面锚点，避免腾空姿势被逐帧拉伸、放大。影子和落脚尘环保持在地面。
- sprites.js 按源路径缓存图片，八个取帧区域共用一张图集。
- characters.html 增加完整跑步图集，便于查看和替换素材。

## 检查

tests/hero-run.test.cjs 检查八帧循环、每轮两次落脚、受阻时停止推进、起停及 30/60 fps 下的步频一致性。tests/sprites.test.cjs 检查透明度、帧边界和固定缩放。浏览器验证键盘移动、点击寻路、反向移动、到达目标后待机和自动走近 NPC 对话。
