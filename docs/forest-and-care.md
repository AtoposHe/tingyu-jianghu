# 听雨林、杏竹医馆与身体状况

## 第二张可行走地图

听雨村南口约在 (552,950)，沿道路向下走会进入听雨林北端。地图按钮“南行 · 听雨林”也会先自动走到南口，再切换地图，不再打开旧的矿点选择浮层。听雨林北口可原路回村，返回按钮同样先沿路北行。背包、钱包、装备、姓名、伤势和资源冷却跨地图保留。

听雨林是 1600×1100 的独立场景，继续使用 WASD / 方向键、点击地面寻路。地形底图包含多段林径、两座溪桥、矿崖、废旧推车、石祠、倒木、树桩、苔石、泉潭、蕨丛与路碑。医馆、竹丛、前景树和人物分层叠加，按脚底深度排序；遮住主角时，近景图层会淡化。

水面、树干、医馆实体、泉潭和部分矿崖不能直接穿越；跨溪必须走桥。新寻路模块与实际移动共用障碍判定。镜头铺满视口并在必要时跟随主角，不在宽屏右侧留下底色条。

## 采矿与随机药草

五处原矿脉 ID 与冷却保留，迁移到林内的真实地点。走近后按 F 即时采集，不需要进度条；点击矿脉只寻路、选点，不自动收取。矿脉各自六十秒恢复。

药草有白芷、赤灵芝。八个潜在采集位置初始随机出现两处；每个空位在 120—240 秒后有概率重新长出药草，种类也随机。同一时间最多四处。未采摘的药草保留，走近按 F 才放进行囊。

刷新结果、采摘状态和下次检查时间写入原钱包存档 `tingyu-forge-v1`。重新进入地图或刷新网页不会重新抽取现有药草，后台也不会直接向背包发放材料。医馆收购白芷每份五金币、赤灵芝每份十二金币。

## 竹林医馆

杏竹医馆位于西北竹林。顾大夫站在屋前，第一行显示“顾大夫 · 医生”，第二行显示“通脉二段”，其 120 灵力符合世界共用属性公式。可以点击医生走近，靠近按 E，或点“寻访顾大夫”自动沿林径前往。

医馆提供：

- 治疗调养：恢复当前气血和灵力。费用为 `5 + ceil((实际缺失气血 + 实际缺失灵力) × 0.08)`；健康且灵力全满时无需治疗、不收费。钱不够时不扣款、不部分治疗。
- 止血散：八金币，战斗外服用恢复三十气血。
- 金疮药：十八金币，战斗外服用恢复七十气血。
- 回气丸：十二金币，战斗外服用恢复二十灵力。
- 收购药草：每次出售一份，扣草和加金币同时保存。

药品进入行囊“物品材料”，点击药品后点“服用”。恢复不超过上限；不需要此药时不消耗。药草与药品也支持原有右键后 F 丢弃。

## 身体状况与姓名

地图按 **C** 或点“身体 · C”。页面显示姓名、境界、当前/上限气血、当前/上限灵力、康健/轻伤/伤势未愈/较重的状态、十八岁、清河镖局出身，以及当前装备计算后的武力、防御和回灵。

姓名可改为 1—10 字，空白、尖括号和控制字符不接受。保存后地图名牌、下方人物信息、战斗卡片、战报和医生的诊疗信息统一使用新名字。名字保存在当前浏览器；输入时不会触发移动键或 C 关闭快捷键。

战斗每次命中和结算后保存气血、灵力缺失量。刷新、回村、出入地图或再次切磋不会免费回满。切磋落败时武师收手，主角至少保留一点气血可行走；其余伤势仍在。首次向武青山学艺时，他会替主角调息一次，保证教学复战仍可体验掌法。正常治疗和用药随后由医馆与行囊承担。

修炼依然只按原有功法增加属性上限；缺失量会保留，因此新增根基能增加当前气血，但不会凭空抹掉全部旧伤。药草暂不提供炼丹配方，医馆尚无后续剧情任务。

## 劈砍节奏

基础劈砍从 1.75 秒缩短到 **0.68 秒**，命中约 **0.26 秒**。待机、抬剑、落剑与收势按短窗口交叠过渡，剑刃在约 0.18 秒内划过。回击前等待缩至 0.22 秒。命中短暂停顿为 22 毫秒，并按实际剩余时长消耗，低帧率也不会整帧停住或被强行拖慢。命中仍只结算一次，不能连点跳过回合。

## 实现与检查

`forest-map.js` / `navigation.js` 为地图与寻路，`forest-resources.js` 为随机刷新；`health.js` / `health.css` 为医馆与身体页面，`forge.js` 扩展统一保存药草、药品、伤势与姓名。`game.js` 管理南北通行和 E/F 交互。素材与生成提示词见 `assets/forest/provenance.json`。

检查覆盖所有矿点、药草位置、医馆和出入口可达，溪水不可穿越，随机刷新与读档不重抽，F 确认采集，伤势持续、治疗与药品消耗、改名同步、既有赠剑/锻造/行囊，以及低帧率劈砍时序。
